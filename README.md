# Quote Of The Day API

This is my practice project while learning Python (Django). A simple back-end service that manages quotes.

## Tech Stack

- Django REST Framework
- MongoDB - `pymongo`, `mongoengine`
- Unit Test - `pytest`, `pytest-django`

## Design & Architecture

- Applying my knowledge of Clean Architecture design pattern
